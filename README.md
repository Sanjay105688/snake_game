
# 🐍 Snake Game

A classic Snake Game built using HTML, CSS, and JavaScript. Control the snake, collect food, increase your score, and avoid collisions.

## 🚀 Live Demo

Play the game here:

👉 https://sanjay105688.github.io/snake_game/

## 📌 About the Project

Snake Game is a simple browser-based arcade game. The player controls a snake that moves around the game area and eats food to increase its length and score.

The main objective is to collect as much food as possible without hitting the walls or the snake's own body.

## ✨ Features

- Simple and interactive gameplay
- Snake movement controls
- Food collection and score tracking
- Collision detection
- Browser-based gameplay
- No installation required to play the live version

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🎮 How to Play

1. Open the live demo link.
2. Start controlling the snake using the controls provided in the game.
3. Collect the food to increase your score.
4. Avoid hitting the walls or the snake's own body.
5. Try to achieve the highest score possible.

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Sanjay105688/snake_game.git
   ```

2. Open the downloaded project folder.
3. Open `index.html` in your web browser.
